AI-Based Restoration of Degraded Images for Semiconductor Inspection

1. Project Overview

This project presents a deep-learning-based image restoration system for degraded semiconductor inspection images.

In semiconductor inspection, microscopic images may suffer from reduced spatial resolution and image degradation, which can make fine structures and defects difficult to identify. The proposed system uses a Residual U-Net architecture to restore degraded low-resolution images into higher-resolution, clearer images.

The model takes a 128 × 128 degraded image as input and produces a 256 × 256 restored image as output.

The final selected model is the U-Net restoration model, which was selected based on its restoration quality and visual performance.



2. Key Features

- Deep-learning-based semiconductor image restoration
- Residual U-Net architecture
- 128 × 128 degraded input → 256 × 256 restored output
- Bicubic upsampling incorporated into the restoration pipeline
- L1-based image restoration training
- PSNR and SSIM-based evaluation
- GPU-accelerated inference
- Batch processing of test images
- Standalone evaluation script for reproducible benchmarking



3. Model

The final model used in this repository is a Residual U-Net.

The network consists of an encoder-decoder structure with residual blocks and skip connections. The encoder extracts hierarchical image features, while the decoder reconstructs the high-resolution image. Skip connections help preserve important spatial information and fine image structures.

Input

128 × 128 × 1

Output

256 × 256 × 1

Model Parameters

Total parameters: 16,325,313



4. Dataset

The model is trained using paired semiconductor images:

- NoisyLR — degraded low-resolution input images
- GT — corresponding high-quality ground-truth images

The dataset contains:

Training images : 3200
Validation images: 320
Test images     : 400

The training dataset is divided into training and validation subsets.

The test set contains degraded images only. Therefore, the restored test outputs are generated using the trained model without ground-truth images being used during inference.

It accepts:

2. Path to the output directory

Run:

13. Evaluation

The model is evaluated using:

PSNR

Peak Signal-to-Noise Ratio measures the pixel-level reconstruction quality between the restored image and the ground-truth image.

Higher PSNR indicates better reconstruction quality.

SSIM

Structural Similarity Index measures similarity in image structure and visual information.

Higher SSIM indicates better structural preservation.

Inference Time

Inference time measures the time required by the model to restore an image and is reported as milliseconds per image.



14. Final Selected Model

After evaluating the implemented restoration approaches, the Residual U-Net was selected as the final model because it provided the strongest overall restoration quality and visual results for the semiconductor inspection dataset.

The final submission therefore uses the U-Net model and its corresponding trained weights for inference.

16. Project Objective

The objective of this project is to improve the quality and effective spatial resolution of degraded semiconductor inspection images while preserving important microscopic structures.

The restored images can assist downstream inspection and analysis by providing clearer representations of degraded semiconductor imagery.
